# Autonomous Drone Project

## Project Goals
- Develop a tablet controlled application for real time drone monitoring and control.
- Fly autonomously in a selected poligon.
- Detect and track nearby drones using computer vision.
- Allow the user to select a detected drone and autonomously follow it.
- Execute high-level commands such as: return home, fly to area, follow, ignore and engage the Target.
- Display drone’s live location, camera feed, and detected targets in the user interface in real time.
